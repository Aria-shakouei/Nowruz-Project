🎯 Project Description

Genius Music App is a JavaFX-based desktop application designed to create a bridge between music artists and their fans. Developed as part of our university's Advanced OOP course, this platform enables:

1. Artists to showcase their work and manage their discography

  

2. Fans to discover new music and interact with artists

  

3. Artist can upload new music and Users can say their opinion and comments or likes for artist.

  

✨ Key Features

  

👨‍🎤 Artist Features

1. Profile management with biography and social links

  

2. Song/album creation with cover art uploads

  

3. Audio upload via microphone recording or file upload

  

4. Lyrics management

  

5. Analytics dashboard

  

👥 User Features

1. Personalized music feed

  

2. Artist following system

  

3. Song liking and commenting

  

4. Lyrics viewing

  

👑Admin Features

1. Artist account approval system

  

2. Content moderation

  

3. Platform analytics

  

🎛️ Technical Features

1. JavaFX GUI with responsive design

  

2. Object-oriented architecture

  

3. MVC pattern implementation

  

4. Persistent data storage
